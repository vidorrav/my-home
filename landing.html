C

Claude Code

Anthropic 官方 CLI · 推荐使用

最常用
1

检查环境

需要 Node.js 18+。没有先去 nodejs.org 装一个。

$ check
node -v   # v18 或以上
npm -v
2

全局安装

$ install
npm install -g @anthropic-ai/claude-code
3

找到配置文件

不同系统路径不一样：

~/.claude/settings.json
# macOS / Linux
~/.claude/settings.json

# Windows (PowerShell)
$env:USERPROFILE\.claude\settings.json
# 即 C:\Users\<你>\.claude\settings.json
4

写入配置

把 YOUR_API_KEY 换成你的 Key。

settings.json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "YOUR_API_KEY",
    "ANTHROPIC_BASE_URL": "https://www.mhcoding.xyz"
  }
}
5

启动 + 验证

$ run
cd 你的项目目录
claude
# 输入：你好，看一下当前目录

报 401？检查 Key 没空格、Base URL 末尾不带斜杠、AUTH_TOKEN 别写成 API_KEY。

O

Codex CLI

OpenAI 官方 CLI · 需 Node 22+

用专属 Key

⚠ 注意： Codex 必须用 Codex 专属 API Key（不是通用 Key），并且要 Node 22 及以上。

1

环境检查

$ check
node -v   # 必须 v22+
2

安装

$ install
npm install -g @openai/codex
3

配置 Provider

~/.codex/config.toml
# macOS/Linux: ~/.codex/config.toml
# Windows:     %USERPROFILE%\.codex\config.toml

[model_providers.mhcoding]
name = "mhcoding"
base_url = "https://www.mhcoding.xyz/v1"
wire_api = "responses"
requires_openai_auth = true

[profiles.default]
model_provider = "mhcoding"
4

写入凭证

单独的 auth.json：

~/.codex/auth.json
{
  "OPENAI_API_KEY": "YOUR_CODEX_KEY"
}
5

启动

$ run
codex
# 首次启动会自动读取 config.toml + auth.json

报"unsupported model"？确认 wire_api 是 responses，不是 chat/completions。

G

Gemini CLI

Google 官方 CLI

1

环境

$ check
node -v   # v18+
2

安装

$ install
npm install -g @google/gemini-cli
3

配置环境变量

~/.gemini/.env
# macOS/Linux: ~/.gemini/.env
# Windows:     %USERPROFILE%\.gemini\.env

GOOGLE_GEMINI_BASE_URL=https://www.mhcoding.xyz
GEMINI_API_KEY=YOUR_KEY
GEMINI_MODEL=gemini-3-pro
4

指定鉴权方式

~/.gemini/settings.json
{
  "security": {
    "auth": {
      "selectedType": "gemini-api-key"
    }
  }
}
5

启动

$ run
gemini
# 进入交互后输入：列出当前目录文件

没认到 Key？检查 .env 没有 BOM 头、变量名拼写完全一致。
