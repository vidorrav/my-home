Claude Code setup

macOS · Linux · Windows

Claude Code is ideal for repository-wide refactors, debugging and feature work. First create a Claude Code group token in the MHcoding console, then use it below.

1

Install on macOS or Linux

Run the official native installer from a terminal.

Terminal
curl -fsSL https://claude.ai/install.sh | bash
2

Install on Windows

Open PowerShell and run the official Windows installer.

PowerShell
irm https://claude.ai/install.ps1 | iex
Prefer npm? Use the alternative installer
npm install -g @anthropic-ai/claude-code
3

Write the settings file

macOS/Linux: ~/.claude/settings.json
Windows: %USERPROFILE%\.claude\settings.json

settings.json
{ "env": { "ANTHROPIC_AUTH_TOKEN": "YOUR_CLAUDE_CODE_KEY", "ANTHROPIC_BASE_URL": "https://api.mhcoding.ai" } }
Use the key created in the Claude Code token group. Do not paste your MHcoding account password here.
4

Enter your project and launch

Open any repository, start Claude Code and complete the first-run prompts.

Terminal
cd your-project claude

Codex CLI setup

Node.js 22+ · Dedicated Codex key

Codex runs in a local sandbox and works well for fast, repository-aware changes. Create a Codex group token in the MHcoding console before continuing.

1

Install Codex globally

Install the latest official package and verify that the command is available.

Terminal
npm install -g @openai/codex@latest codex --version
2

Create the provider configuration

Save this as ~/.codex/config.toml. On Windows, use %USERPROFILE%\.codex\config.toml.

config.toml
model_provider = "mhcoding" model = "gpt-5.6-sol" model_reasoning_effort = "high" network_access = "enabled" disable_response_storage = true [model_providers.mhcoding] name = "MHcoding" base_url = "https://www.mhcoding.ai/v1" wire_api = "responses" requires_openai_auth = true
3

Create the authentication file

Save your dedicated token as ~/.codex/auth.json.

auth.json
{ "OPENAI_API_KEY": "YOUR_CODEX_KEY" }
4

Launch Codex

Start it inside the repository you want Codex to work on.

Terminal
cd your-project codex

Gemini CLI setup

Node.js 18+ · Dedicated Gemini key

Gemini CLI is a strong fit for multimodal development workflows. Create a Gemini CLI group token in the MHcoding console before configuring the client.

1

Install Gemini globally

Install the official package and confirm the installed version.

Terminal
npm install -g @google/gemini-cli gemini --version
2

Write the environment file

Save these values in ~/.gemini/.env. On Windows, use %USERPROFILE%\.gemini\.env.

.gemini/.env
GOOGLE_GEMINI_BASE_URL=https://api.mhcoding.ai GEMINI_API_KEY=YOUR_GEMINI_CLI_KEY GEMINI_MODEL=gemini-3.1-pro-preview
3

Select API key authentication

Add this to ~/.gemini/settings.json so Gemini CLI uses the token above.

settings.json
{ "security": { "auth": { "selectedType": "gemini-api-key" } } }
4

Launch or make a multimodal request

Run Gemini normally, or include a local screenshot, mockup or document in your prompt.

Terminal
cd your-project gemini # Example with a design image: gemini -p "Generate a React component from ./design.png"

Grok Build setup

macOS · Linux · Windows

Grok Build supports long-context coding sessions and a terminal-first workflow. Confirm that Grok Build is enabled for your account, then create a Grok Build group token.

1

Install on macOS or Linux

Run the native installer from a terminal.

Terminal
curl -fsSL https://x.ai/cli/install.sh | bash
2

Install on Windows

Open PowerShell and run the Windows installer.

PowerShell
irm https://x.ai/cli/install.ps1 | iex
3

Create the model profile

Save this as ~/.grok/config.toml. On Windows, use %USERPROFILE%\.grok\config.toml.

config.toml
[cli] installer = "internal" [models] default = "grok-4.5" default_reasoning_effort = "high" [model.mhcoding] model = "grok-4.5" name = "Grok 4.5" base_url = "https://www.mhcoding.ai/v1" api_key = "YOUR_GROK_BUILD_KEY" context_window = 500000
Model names and context limits depend on the routes enabled for your account. Use the exact model ID shown in the MHcoding console.
4

Enter your project and launch

Start Grok Build in the repository you want it to inspect.

Terminal
cd your-project grok

Frequently asked

A few things worth knowing.

Need help with a client or model? Email support@mhcoding.ai.

Is MHcoding a subscription?

No. The service is usage based. Add balance when you need it and your cumulative top-up total determines your pricing tier.

Can one key work with every tool?

Most supported routes can use a general API key. Codex CLI may require a dedicated Codex key, which you can generate from the dashboard.

What should I use as the base URL?

Use https://api.mhcoding.ai for Claude Code and Gemini CLI. OpenAI-compatible clients and Codex provider configuration commonly use https://www.mhcoding.ai/v1.

How do pricing multipliers work?

A multiplier is applied to the reference model cost. Lower multipliers consume less balance for the same request. Check the live pricing page for model-specific rates.

Where can I see usage and remaining balance?

The dashboard shows current balance, request logs, token usage, and charges in one place.
